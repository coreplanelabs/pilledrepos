# Interface rules

Follow the user's Polylane and Repo Lore direction: DM Sans for copy, DM Mono for
numbers, Polylane green, existing animated pill mark, and the source/attribution
footer. Use a 16px body scale, 14px supporting text, consistent 8px spacing steps,
and a separate visible label and bordered repo input. Keep the main actions easy
to tap. The compact theme selector stays in the header.

Review the whole app against these official skills before final visual approval:

- [Vercel Web Design Guidelines](https://skills.sh/vercel-labs/agent-skills/web-design-guidelines):
  focus, labels, touch targets, readable data, URL state, and layout stability.
- [Anthropic Frontend Design](https://skills.sh/anthropics/skills/frontend-design):
  type scale, spacing, hierarchy, long content, and screenshot critique.

The user's brand and layout choices take precedence over a skill's aesthetic
preferences. Verify home, sort directions, loading/errors, details with short and
long descriptions, light/dark themes, and mobile widths. Preserve image dimensions
and keep async loading outside document flow to prevent layout shifts.
